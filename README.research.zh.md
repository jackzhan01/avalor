# Avalor 研究交接：尝试、结论与下一步

整理日期：**2026-10-27**。这是一份给队友的研究总览，依据仓库文档、代码、提交记录及本地实验目录整理；历史实测主要记录于 2026 年 8–9 月。本次整理没有新增付费模型调用，也没有重新跑统计实验。产品介绍和使用说明见 [README.md](README.md)。

**研究主线：怎样把阿瓦隆的公开记录变成可靠判断，再把判断变成有效协作，同时不暴露不该公开的身份信息？** 我们先研究结构化战报能支持多少推断，再研究语言和多智能体能否补足它，最后转向真人视频建立更可信的评测材料。

## 先读这五条结论

1. **概率计算已有可用基线。** 小规模身份空间可以精确枚举；硬约束守住规则，行为似然负责加权。实测参数、轮次分层明显改善了历史标定，但旧参数拟合含测试数据，不能把旧分数包装成完全干净的留出评测。
2. **更会预测人怎么点车，不等于更会赢。** 离线决策研究发现了这一区别。产品 V1 最扎实的输出是身份概率、联合车况风险和规则证明；单张票的胜率差通常小到无法可靠区分。
3. **LLM 直接读战报、自己记笔记、多人反复表达同一判断，都没有自动变成更好的信念。** 候选生成有价值，但概率仍应由数学层负责；相关错误和重复计证据是主要失败模式。
4. **完整模拟器能跑，不等于智能体已达到真人高手水平。** 认知账本、事实来源、公开发言隔离等机制陆续建成，但实盘主要是少量诊断局，版本之间改动较多，尚无可靠的多局胜率结论。
5. **真人视频已打通“证据 → 审阅 → 截止点输入 → 独立答案 → 评分”。** 目前仍是小样本试点。三局单次身份推断和一组去发言消融，不能证明语言总体有效或无效。当前更缺独立审阅和受控评测，而不是更多提示词。

## 1. 从真人战报建立信念基线

**问题。** 不靠“看起来像坏人”的直觉，仅凭点车、座位级票型、任务结果和合法私有视野，能推到什么程度？

**尝试。** 整理 AvalonLogs 的 **12,882 局**，先做字段、牌型与角色归一化，再依次比较纯硬约束、手调行为参数、实测参数、轮次分层和角色行为证据。7–10 人局占 6,002 局；牌型有 73 种，按参数对应的信息结构分池比只保留完全相同牌型更合理。

**结果。**

- 硬约束检查中，12,882 局的真实坏人组合均未被排除，3,729 个确定性断言未发现错误。这支持规则层的可靠性，但排除法本身很弱：9 人局打完，平均仍剩约 57.2 / 84 种阵营组合。
- 早期标定中，阵营 Brier 从无信息基线 **0.2345**、纯硬约束 **0.2234**，经过实测参数和轮次分层降到 **0.1461**。Brier 越低越好，衡量的是概率质量，不是简单猜对率。
- “上自己的车像坏人”被推翻：坏人/好人的上票率比只有 **1.04**。好人从车外判断干净车和脏车的上票率不同，说明好人的票也有信息。
- 统一削弱证据的 `damping=0.5` 使本来就不够自信的模型更差；最终取 1.0。票的判别力随轮次提高，早期与后期不能共用同一强度。
- 角色层也尝试按轮次拆参数，却让梅林识别 Top-1 从 **27.1% 降到 26.7%**，因此回退。记录给出的解释是每角色样本更少，细分后的方差抵消了收益；不能因为阵营层分层有效就照搬到角色层。

**冻结状态。** 后续以联合角色后验、温度 λ=0.4 冻结为 Belief Engine V1。在另一套 **320 局**冻结评测中，第 5 轮阵营 Brier 为 **0.0937**，阵营基线为 0.0963；前四轮则略落后。这个数字与上面的 0.1461 来自不同评测口径，不能连成同一条提升曲线。

**仍未解决。** 部分行为参数在全语料上拟合，包含测试数据；9/10 人局比 7/8 人局更难；稀有角色区间宽；角色置信度尚未得到可靠标定。新的研究应按整局切分，只在训练集重拟合参数。

依据：[数据审计](research/AUDIT.md)、[早期实验](research/README.md)、[参数分池](research/PARAMETERS.md)、[冻结评测与缺口](research/BELIEF-V1.md)。

## 2. 从身份概率走到离线决策

**问题。** 知道谁更可疑以后，能不能可靠地比较两辆车或上票/下票？

**尝试。** 在精确后验上计算整辆车的联合风险，再用蒙特卡洛推演估计动作后的胜率。研发中先后尝试固定信念、逐座位更新、联合粒子表示、补齐点车与票型似然、整车选择，以及连否压力和角色视野修正。

主要教训有三条：

- **必须保存“几个人之间的关系”。** “这车至少一个坏人”不是几份互不相关的座位分数。逐座位更新无法完整表达它，联合世界表示才能保留这种约束。这里的粒子用于推演内的近似更新；冻结信念层本身仍然精确枚举。
- **先校准模拟过程，再相信动作分数。** 初版模拟好人胜率约 0.17–0.28，明显低于对应真人统计，曾明确停止解释它的胜率差。修正后的产品版本仍偏悲观，尤其 8 人局两项校准指标超出容差。
- **拟合行为与改进策略是两件事。** 历史特征让真人点车 Top-1 预测从 0.144 提到 0.204，却没有改善模拟对局表现。在现有冻结模型及评测下，真人点出的车比只读结构化记录的风险排序更干净；这提示缺少交流信息，不是“任何算法都无法利用日志”的证明。

**产品结论。** V1 采用“穷举合法车风险 → 短名单推演”。40 个真实决策点上，没有一张票的胜率差达到 `lean` 或 `strong`；两随机种子的差值同向率只有 0.675。因此保留车况方向 `riskDirection`，不强行报有把握的胜率建议。模拟器的共同偏差也不能被视为一定会在差值中完全抵消。

产品边界已冻结：UI 只调用 `analyzeGame(events, game)`，这条算法路径完全离线。产品中的联网 AI 参谋是另一个入口，不能与离线算法或研究实验混为一谈。

依据：[PRODUCT-V1.md](PRODUCT-V1.md)；历史诊断见提交 `185f608`、`cbd6fc5`、`c1b0b6a`、`9bcd15a`、`c2ea183`（可用 `git show -s --format=full <提交号>` 读取实验记录）。

## 3. 直接用 LLM，以及“LLM 出主意、数学算概率”

**问题。** LLM 能否直接替代数学推断？如果不能，适合承担哪个环节？

**做过的比较。**

- **直接读结构化战报。** 历史实验的 800 个决策点中，数学层阵营 Brier **0.120**，LLM **0.182**；LLM 点出的车坏人载荷约为随机的 **1.149 倍**，并未胜过随机。结论限于当时模型、提示和信息集，不代表所有模型。
- **生成候选，再由数学筛选。** 200 个队长决策点，每次生成 5 辆候选车，命中风险排序前 1% 的比例 **0.330**，同样大小的盲选名单为 **0.093**。这支持候选生成的用途；没有证明它超过穷举，更没有证明实战胜率提升。
- **记忆消融。** 只给完整日志，LLM 的判断没有随轮次明显改善；携带自己的旧笔记反而变差，表现出锚定。给数学后验后有所改善，但概率标定仍弱于数学层。
- **坏人目标与欺骗。** 中性提示下，坏人智能体经常直接指出自己的队友；明确要求为坏人阵营争胜后，实验里的欺骗指标由负值转正。更复杂的示例与自检提示反而不如简洁的明确目标。

**结论。** LLM 在“列出可选走法、组织语言”上有用途，但不能因为语言流畅就把它的概率当作经过标定的概率。提示改变坏人是否愿意隐藏信息，也会改变整桌难度，胜率上涨未必意味着好人推理更强。

依据：`research/llm-*.test.ts`、`research/hybrid-v0.test.ts`；实验记录见提交 `4c973df`、`819fbe1`。早期社会信号的质量轴后来发现标注有误，解释阈值应以 `44b5e36` 的修正为准，不沿用旧的“0.40”口径。

## 4. 让社会信号进入闭环：发现共同错误与重复计证据

**问题。** 每个座位都读局、发言，再把保踩作为软证据喂回后验，是否能补足结构化日志？

**尝试。** 比较静默、合成社会信号、LLM 发言、读取他人发言、读取数学后验等条件；随后审计错误是否集中、怀疑是否持续，以及相同依据是否被多人重复计入。

**发现。**

- 初次闭环每臂 100 局：无数学记忆的 LLM 桌好人胜率 **0.311**，静默桌 **0.318**；加数学后验的 LLM 桌达到 **0.408**。进一步诊断发现，后一变化伴随坏人欺骗能力下降，不能只解释成好人更会读局。
- **不互相读发言，也会集体踩错同一个好人。** 该条件下，多人集中误踩约为按自身误踩率预期的 **3.74 倍**。读他人发言并非这种现象的必要条件，但会让已有怀疑更难消退。
- 按“同一轮、同一目标”聚类并用相关性折扣后，修掉了部分重复计证据的问题。修正后的第 5 轮 Brier：静默 **0.1838**，LLM 单独 **0.2039**，加他人发言 **0.2170**，加后验反馈 **0.1903**。语言各臂仍劣于静默；合成信号则为 **0.1288**。

**结论。** 平均信号质量相同，不代表信息价值相同。错误若一起出现、一起持续，简单相加或统一降权都不够。相关性折扣是局部修复，尚未把当时的 LLM 社会信号变成净有益、已标定的输入，所以这一路没有并入产品 V1。

依据：`research/closed-loop.test.ts`、`research/error-structure.test.ts`、`research/overcounting.test.ts`、`research/social-metrics.ts`；提交 `44b5e36`、`dfdba48`、`931ff05`、`25ba5da`。这些是当时实验臂的结果，不能与后来视频上的单次模型分数直接比较。

## 5. 完整十人模拟器与 M5–M5.5 认知实验

这条线与上一节“数学推演中注入社会信号”不同：这里由十个独立座位智能体实际完成发言、点车、上/下票、任务牌、女神和刺杀，裁判推进整局。

**基础设施已完成。** 座位只能拿到自己的合法视野；公开回放与私有轨迹分开；动作可重放；有预算、版本指纹和检查点。离线续跑测试验证已定动作不会重新询问，重放结果与不中断运行一致。脚本智能体用来检验裁判，不充当真人行为模型。

认知实验沿着实盘暴露的问题演进：

1. **M5：事实、说法、推论分层。** 模型曾把“自称忠臣”和“女神公开报好”当成真身份依据。认知账本把裁判事实与玩家说法分开，让未证实前提跟着推论走。
2. **M5.1：事实引用与公开协调。** 初版提示让模型引用根本没展示的事实 ID，导致 871 条引用全被判未证实。补齐 ID 管道，并加入“公开说什么，别人才能配合”的结构。
3. **M5.2：派西维尔对跳与退水。** 将派权竞争作为公开过程记录。试跑出现身份声称，但真派把梅林/莫甘娜候选对直接说了出来，证明动作合法、私下推理正确，仍可能因泄露而战略失败。
4. **M5.3：私有规划与公开表达分开。** 规划者保留合法私有信息，发言者只拿公开记录和经检查的沟通意图；加入非干涉测试与发言检查。这降低直接传递秘密的通道，但文本检测器并不完备，不能宣称解决了所有语义泄露。
5. **M5.4：修接线与明确房规。** 两局实盘的 203 份遥测中，`social/contest` 曾全部为 null，原因是版本判断使模型输出被丢弃；后来改为能力表。另补坏人任务牌协调房规、投票检查和刺杀信息呈现。刺错人仍是合法失误，不能由裁判替智能体纠正。
6. **M5.5：引用、声称目的与信息隔离修复。** 修复后真实试跑出现真派起跳、莫甘娜对跳，前两辆车分别以 1:9、3:7 被否；也暴露了字段在解析时丢失等问题，已加回归检查。

**真实停止点。** M5.5 修复后的局在第 82 次请求超时，续跑成功；第 112 次请求遇到 provider 的 `invalid_request_error / invalid_prompt` 后终止，尚未进入任务阶段。失败提示未完整保存，不能确定触发原因。检查点未保存拒绝遥测、失败请求缺少可审计的实际提示，这两条缺口仍在交接记录中。不要继续旧失败局来冒充完整实验。

**能与不能得出的结论。** 已得到一系列可复现的工程失败诊断与机制修复；尚无多 seed 的稳定实力比较。仓库精选的三局旧回放共享一副牌，而且提示、策略和 schema 同时变化，三局坏人 3:0 不是三个独立证据。M5.4 后来虽跑出一局好人胜，也不能说明已胜过旧版。M5.5 记录的累计 **$61.5373** 是当时该模拟研究的账本，不是整个项目的总费用。

依据：[模拟器](research/simulator/README.md)、[三局回放及限制](research/simulator/games/README.md)、[M5](research/simulator/cognition/README.md)、[M5.1](research/simulator/cognition/README-M5.1.md)、[M5.2](research/simulator/cognition/README-M5.2.md)、[M5.3](research/simulator/cognition/README-M5.3.md)、[M5.4](research/simulator/cognition/README-M5.4.md)、[M5.5 最后实盘与暂停点](research/simulator/cognition/README-M5.5.md)。部分旧标题写着“尚未实盘”，后来已有新记录；按后续实盘章节理解，不把阶段快照当现状。

## 6. 转向真人视频：先造可信输入，再评模型

**转向原因。** AvalonLogs 没有可用的真人讨论文本，模型自博弈又容易让提示缺陷、裁判接线和模型能力互相混淆。下一步需要观察真人怎样保踩、对跳、推动换车和藏身份。

**建设过程。** 从短片段语义标注试点，扩展到全片公开时间线，再改成每次点车一个 block 的 `input.zh.txt` 与独立 `label.json`。OCR 读字幕和板面，ASR 提供另一条机器证据通道；人工/agent 审阅通过追加修正链保留来源，按公开截止点生成样本。

贯穿管线的约束是：

- 观众名单、带身份的发言人标签、片头剧透、赛后答案都不能进入当时的模型输入；答案只给评分器。
- **先截取公开事件，再组装正文**，不能先读完整局后在文字层删后文。
- 票型保留座位级信息；没记、看不清、明确上/下票分开。车过了还是被否，以公开结果为准，不从票型补猜。
- 字幕覆盖不等于原始讨论完整；说话人读不到就留空；未核实房规不写成标准事实。
- 修订产物另存，历史 input/label 保持不变；补录事件不倒插序号，让旧截止点保持可追溯。

**三局模型试跑。** 历史记录中，gpt-6-astra 各跑一次：第一局阵营准确率 **0.20**、Brier **0.3501**、具体身份准确率 **0.10**；第二局 r1 为 **0.80 / 0.1609 / 0.30**；第三局为 **1.00 / 0.0839 / 0.40**。

这些不是一条进步曲线：对局、覆盖区间、可用任务结果数不同，第一局还有后来认定有误的覆盖说明和未核实规则。第三局虽然阵营全对，引用审核仍发现张冠李戴；说明“猜对答案”和“证据可靠”也要分开测。

**第三局 m3 去发言消融。** 在第 3 轮任务结果后的同一截止点，对比完整公开信息 A 与只保留客观事件 B，客观字段和提示保持一致，每条件仅一次调用：

- 阵营准确率都是 **0.60**，十个座位的二元判断完全相同，只打平“全判好人”基线。
- Brier 分别为 **0.2335 / 0.2405**；具体身份准确率 **0.20 / 0.00**。
- 可得结论只有“这一次、这个截止点上，删除发言没有改变阵营判断”。没有重复采样，不能把差值解释成稳定因果效应，也不能得出发言无用。

视频身份推断至此共 **5 次付费调用**：三局各一次，加 m3 两条件。后面的扩源与管线工作没有新增付费推断。

依据：[数据契约](research/video-benchmark/SPEC.md)、[操作说明](research/video-benchmark/README.md)、[第二局修订与试跑](research/video-benchmark/HANDOFF.v6-game2-r1-trial.md)、[第三局及三局对照](research/video-benchmark/HANDOFF.v8-game3-trial.md)、[m3 消融](research/video-benchmark/HANDOFF.v9-m3-ablation.md)。

## 7. 视频扩源目前做到哪一步

## 9. 队友接手顺序与资料位置

建议按以下顺序推进，避免重复已经证伪的尝试：

1. **先整理数据与实验登记。** 确认每个来源的规则、截止点、审核范围、修订目录和 input 哈希；将单次诊断与正式评测分开。原始材料位置见下节。
2. **补评测质量。** 优先独立复核少量视频、确认剪辑缺口与角色标签，再做多局、多截止点、重复采样的“客观事件 / 客观事件+发言”对比，报告逐局效果和按局不确定性。
3. **重建干净数学基线。** 只在训练局拟合参数，用相同信息集和截止点评价；不要沿用含测试数据的历史拟合后声称完全留出。
4. **若继续自博弈，先修审计缺口。** 保存拒绝遥测和可审计的失败提示，再锁定模型、提示、规则、预算与 seed 设计配对实验。不能只把合法动作率或测试全绿当作策略质量。
5. **课程贡献优先做小博弈与均衡分析。** 让模拟器和视频检验明确问题；不要让扩充提示词与下载更多视频替代理论工作。

主要代码入口：`src/lib/inference/` 是信念层，`src/lib/decision/` 是冻结离线决策，`src/lib/social/` 与 `research/*.test.ts` 是早期社会信号实验，`research/simulator/` 是完整对局环境，`research/video-benchmark/` 是视频管线。动算法前先读 [AGENTS.md](AGENTS.md) 和 [PRODUCT-V1.md](PRODUCT-V1.md)。
