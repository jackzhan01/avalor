# 科研总结：数学模型 → LLM 十人局 → 真人对局评测

我们一直在研究同一个问题：**AI 能不能根据阿瓦隆中的行动和发言，判断谁是好人、谁是坏人，并据此打好这局？** 主要走了下面三步。

## 1. 先尝试用数学模型推理

最初参考了两篇论文：[CSP4SDG](https://arxiv.org/abs/2511.06175)，用规则排除不可能的身份、给剩余可能性打分；[GRAIL](https://arxiv.org/abs/2506.17788)，把概率推理与 LLM 的语言能力结合。我们借鉴这些思路，没有完整复现论文的方法。

我们的做法是：列出可能的身份组合，用任务结果排除不可能的情况，再根据点车和票型更新每个人是坏人的概率，最后尝试模拟后续对局，比较不同走法。

在 **12,882 局真人线上战报**中，规则排除没有误删真实的坏人组合；用真人行为数据调整参数后，概率判断也明显改善。但这些战报没有讨论内容，模型难以利用保踩、对跳和欺骗。部分历史参数还用了全量数据拟合，评测不够严格。

**结论：数学模型能提供有用的身份概率和车况判断，但我们没有证明它能靠这些信息稳定打好整局。**

## 2. 再让 LLM 直接打十人局

接着让十个 LLM 分别扮演一个座位，只看到各自应当知道的信息，自己发言、点车、上/下票、出任务牌和刺杀。我们陆续尝试了策略提示、记忆、区分事实与玩家说法，以及把私下思考和公开发言分开。

效果并不理想：模型会把别人的话当事实，反复坚持错误判断，缺少有效协作，甚至把梅林相关的私有信息直接说出来。早期留档的三局都是坏人连挂三把、好人 0:3；不过它们用了同一副牌，不能当作三次独立实验。后来出现过好人获胜和真正的派西维尔对跳，但仍缺少多局、同条件的比较。

**结论：会解释牌局，不等于会打牌。加提示和记忆解决了一些问题，但还没有得到稳定、可信的十人局智能体。**

## 3. 最后收集真人对局，测试 LLM 能不能读懂

为了把“能否读懂局势”和“能否自己打好一局”分开，我们开始收集真人视频，将发言、点车、票型和任务结果整理成文字，只把当时公开的信息交给模型，再用单独保存的真实身份评分。

目前已整理四局，其中三局各做了一次 gpt-6-astra 身份推断：**判断好坏阵营的准确率分别是 20%、80%、100%；猜中具体身份的比例是 10%、30%、40%。** 三局的长度和已揭晓任务数不同，第一局输入还有后来发现的问题，因此这不是一条“模型越来越强”的曲线。

我们还在第三局打到第 3 轮时做了对照：一组保留玩家发言，一组只给客观行动记录。**两组阵营准确率都是 60%，只打平“把所有人都判成好人”的简单基线。** 有发言的一组具体身份稍好，但每组只跑了一次，不能据此判断发言总体有用或无用。

**当前结论：LLM 在部分真人局面上能判断对阵营，但表现差异很大；玩家发言能否带来稳定提升，仍没有得到验证。** 下一步应在相同截止点、更多对局和重复测试中比较“有发言”和“无发言”，再决定如何改进模型。
