# Belief Engine V1 —— 冻结基线

一次性、且唯一一次在留出集上的评估。λ 在此之前已由验证集定死（`roles.ts` 的 `ROLE_TEMPERATURE = 0.4`），本文件的任何数字都没有回流到模型。

**协议**：train `i%4==0` / validation `i%4==2` / test `i%2==1`，按**局**切分。λ 只在验证集上扫。置信区间是**按局**重采样的百分位自助法（座位之间共享证据，按座位重采样会给出窄好几倍的假区间）。

复现：`npx vitest run --config research/vitest.config.ts research/belief-v1-final.test.ts`

## 冻结决定

按事先约定的标准：**λ 落在 0.2–0.4 区间内（0.4）、阵营标定保住（R5 反超）、角色收益保住（与 λ=1 在噪声内）** ——
**冻结为 Belief Engine V1。**

## 四个已知、未解决的缺口

1. **参数拟合泄漏**：`soft.ts` / `merlin.ts` / `percival.ts` / `oberon.ts` 的行为参数是在**全语料**上测的，含测试集。
   它们是几万次观测的聚合条件频率，砍掉一半只会移动约 1/√n（坏票表 n=24,057，不到一个百分点），
   但**不是零**，所以留出集的数字略微偏乐观。干净的做法是只用 train 重拟合，尚未做。
2. **置信度机制未解决**：原始熵阈值分不清「候选少」和「学到了东西」——9 人局刺客仅凭数数就是 log₂(3)=1.58 bits。
   验证集上最尖锐的 2.6% 读数命中率 0.280、全局 0.213，**没有任何阈值配得上「有把握」**。
   阈值留在 1.6（调温后从行为证据几乎不可达，这是诚实状态）。正确做法是**相对于每个角色自身的无信息熵**、逐角色标定。
3. **9/10 人局明显更弱**，见上。
4. **两层的阵营数字仍有分歧**（λ 把它压到最大 0.066），已在 `coherence.test.ts` 里守着上界。
