# 阿瓦隆真人对局逐轮身份推断：实验流程、结果与评审请求

2026-11-23 · Algorithmic Game Theory 课程项目 · 评审用快照

**请评审三个问题：模型能从后续对话和行动中多读出多少身份信息？哪些差异能归因于证据增加？哪些结果需要撤回或重跑？** 本文提供关键数字和一个可复现的泄漏反例，可以单独转发。文末的仓库路径供有数据访问权的评审复算。[在线逐轮报告与费用](https://avalon-nlu-role-lab.milkycomet22.chatgpt.site/comparison)

## 1. 先读这一条：十人局有已验证的标签泄漏

整理本文时，我们对已经发出的请求做了一个简单测试：抹去所有玩家发言和行动，只看提示中的公开角色名单，再给出派西维尔按规则应该看到的两个候选座位。**一个确定性规则在 22/22 局都认出了真梅林。** 对每个模型的 104 份不同十人局派西输入逐份检查，结果均为 104/104。全桌身份任务也受影响，名单里的第一个角色在 22/22 局都是 1 号的真实身份。

**泄漏从哪里来。** 制作十人局清单时，代码遍历私有底牌文件的座位，用 Python 的 `Counter` 统计各角色张数，再转成字典。张数本身可以公开，但字典保留了各角色第一次出现的顺序。文件里的座位键是字符串，顺序为 `1, 10, 2, 3, …, 9`。制作请求时按字典顺序打印板子，全桌任务的角色映射和 JSON 枚举也沿用它。逐局核对，**22 局名单顺序全部吻合**。六人局使用固定板子和固定提示语，没有这条逐局变化的编码渠道。

**实例。** 在十人局 `BV19D7565EZg`，派西看到 6 号和 8 号。提示中的名单依次是“忠臣、刺客、奥伯伦、派西维尔、梅林、莫甘娜、莫德雷德”。因为梅林排在莫甘娜之前，两人中按上述字符串顺序先出现的 6 号就是梅林。这个判断在第一句发言之前就可以完成。

**对结论的修正。** 下文保留十人局测量值，供定位影响和重跑后比较。它们能说明模型在这批有泄漏的输入上输出了什么；据此判断模型的真人读牌能力、评价十人局谁更强，或解释六人和十人之间的差异，都需要干净重跑。这个反例证明答案可以从提示恢复，尚未证明某个模型实际用了这一捷径。泄漏贯穿各轮，所以只比较同一局的前后轮也不能消除影响。此前网页和口头总结中的十人局解读应以此修正为准。

## 2. 从博弈论问题到两个可测任务

项目起点是 Carminati 等人的 *Hidden-Role Games*。理论论文研究给定通信和协调条件后，阵营可以达到怎样的博弈价值。真人复盘让我们考察一个更小的问题：在信息集受限时，模型能否随公开证据更新对隐藏身份的判断？下面两个任务都在固定录像或聊天记录上离线运行。模型的回答不影响下一轮，实验也没有测量点车、上票、刺杀或最终胜率。[理论阅读与实验桥接](../theory/carminati/experiment-bridge.md)

| 条件 | 模型在轮末看到什么 | 输出与标签 |
|---|---|---|
| A · 旁观者猜全桌 | 开局板子与规则、截至本轮的玩家发言和已记录的公开行动，包括点车、上票／下票和任务结果 | 给每个座位分配一个具体角色；用真实底牌逐座位评分。可另算好坏阵营和整桌全对率 |
| B · 派西维尔认梅林，累计发言 | 自己的座位、两个拇指位、开局板子，以及从开局到本轮的玩家发言。玩家可以在发言中谈论行动、说谎或跳身份 | 给两个候选人分配梅林概率；用真实梅林座位评分 |
| B 的对照 · 仅本轮发言 | 初始视野与 B 相同，只给当前轮的玩家发言；两种 B 输入都剔除系统行动记录 | 同一道二选一题。第二轮起与累计条件逐局逐轮配对 |

例如，派西若看到 2 号与 4 号亮拇指，模型给 2 号 70%、4 号 30%，而真梅林是 4 号，这次的准确率得 0，给真梅林的概率是 0.30，Brier 分数是 0.49。旁观者任务则要同时判断包括派西本人在内的全桌座位。两题所给视野和答案空间都不同，准确率应在各自任务内部比较。

| 数据 | 样本来源与底牌 | 快照与清洗 |

| 十人局「圆桌谜局」 | 22 局中文真人桌游录像，含仓库原有 4 局和新增 18 局。按制作方给观众的身份叠层单独记录底牌；20 局常规板、2 局含执剑人和破壁人 | 从视频的玩家发言及公开行动整理记录，使用 `yuanzhuo22-preprocess-v1`。统一部分排版、修正能核实的转录错误、删部分口癖，保留否定、改口和玩家自述。没有做发言摘要，转录也没有逐字双人复核 |

十人版发布包原有 **112 对输入与标签**：22 份整段录像输入、59 份任务结算、30 份投票结算、1 份强制组车。正式逐轮实验仅使用任务结算。对另有明确任务结果的 4 轮，从整局输入截到当轮结果及紧随其后的失败牌数，最终得到 **63 个轮末**，五轮分别覆盖 **22、22、14、4、1** 局。部分录像在整盘游戏结束前就已截断，因此“最后一个可见轮末”因局而异。两份数据共 **42 局、145 个轮末**，同一局的多个快照共享底牌。

每个轮末重新发送独立请求。上一轮预测、后续轮次、评测标签和录像标题都不作为显式输入。派西的初始视野由真值投影生成，只应暴露自己和两个候选座位。十人局的顺序泄漏说明，只检查请求里有没有名为 `label` 的字段，无法充分验证信息隔离。[六人局数据来源](https://sstepput.github.io/Avalon-NLU/) · [十人局预处理说明](../data/video-benchmark/releases/yuanzhuo22-preprocess-v1/README.md)

## 4. 实际执行顺序、模型和请求数

1. **Gemini 六人局。** 先做每局末轮的全桌身份推断。一次 HIGH 档试跑没有得到有效预测；正式基线使用 `gemini-4-hydrogen`、MEDIUM 思考档、温度 1。20 局末轮得到 20 份有效回答，共猜对 73/120 个具体身份、116/120 个阵营，5/20 局全桌身份全对。随后扩展到全部 82 个轮末和三种输入条件，原先的 20 份末轮回答直接复用。Google 直连与 OpenRouter 上的 Google AI Studio 回执均有保存。
2. **Gemini 十人局。** 用同一模型和思考档通过 OpenRouter 跑 63 个轮末。全桌和派西分别使用十人板子及中文说明。先冻结请求，保存输入摘要，再解析和评分。
3. **千问六人和十人局。** 通过 OpenRouter 的 DeepInfra 端点调用开放权重 `qwen/qwen3-32b`。和 Gemini 逐份核对了 **393 份不同输入**的系统指令与用户消息。千问采用服务商默认思考设置，没有强行套用 Gemini 的 MEDIUM 档。
4. **Jev 六人和十人局。** 通过 OpenRouter Decisions API 调用 `typesafe/jev-1.14`，只做派西任务。将原视野和发言放进 state，用 Choice 返回两座位概率。与对应 Gemini 条件逐份核对了候选顺序和对话文本。Gemini 和千问报整数百分比，Jev 使用接口返回的概率。

第一轮的累计发言和仅本轮发言完全相同，共用一份回执。对同时跑 A、B 及 B 对照的模型，六人局需要 `3 × 82 − 20 = 226` 份不同请求，十人局需要 `3 × 63 − 22 = 167` 份。Jev 只有两种 B 条件，两份数据分别需要 144 和 104 份。**主比较共 1,034 份不同回执，对应 1,160 条条件评分；其中 226 份六人 Gemini 回执为历史复用，新增 808 份。** 主实验对每种不同输入保留一次有效回答。原始回执、输入摘要及独立评分文件均保存在本地。欺骗训练模型目前只做了候选调研；这批结果没有检验“学过欺骗是否更会识破伪装”。[模型调研记录](avalon-model-survey.html)

## 5. 评分口径

- **全桌身份**按猜对座位数除以人数。另算阵营准确率、整桌全对率和角色张数合法率。输出给全座位填了可用角色名即逐座位计分，张数违规也保留。Gemini 两组和千问六人组均全部张数合法；千问十人组只有 **49/63** 份张数合法。若改用约束解码，模型间比较可能改变。
- **派西二选一**猜对得 1，猜错得 0，五五开得 0.5。记模型给真梅林的概率为 `p`，Brier 为 `(1 − p)²`，越低越好。一直报 50% 的 Brier 是 0.25。另存 `max(p, 1 − p)` 衡量自报信心。Brier 同时反映区分能力与概率质量，单靠这个分数不能诊断校准误差的来源。
- **总体与趋势**先在每局内平均各轮，再等权平均各局。第一轮到第三轮的变化只取同时有两轮的局，先逐局相减；比较两个模型时先在同一局同一轮相减。95% 区间用按局重抽样 3,000 次的百分位数。六人、十人是独立样本，两组增幅之差分别在组内重抽样。区间仅反映样本局之间的变异，无法覆盖同一输入反复抽样的全部变异；多个指标的区间也没有做多重比较校正。
- **基线**随机认梅林的期望准确率为 50%。实际提示始终把座号较小的候选人列在前面；始终选较大座位，在这 20 局六人局中已可得 60%（12/20），对解读 Gemini 的 63.3% 很重要。全桌按板子随机合法分牌，期望座位身份准确率为各角色比例的平方和：六人局 22.2%，常规十人局 22%，特殊十人局 16%。这些是无信息理论基线。

## 6. 测到什么，以及可以怎样解读

下表为每局等权的均值。派西列均用累计发言。十人局数字是**泄漏版本的历史实测**，留作修复前的对照。

| 数据 | 模型 | 全桌具体身份准确率 | 派西二选一准确率 | 派西 Brier |
|---|---|---:|---:|---:|
| 六人 | Gemini | 37.1% | 63.3% | 0.194 |
| 六人 | Qwen3-32B | 30.6% | 49.4% | 0.272 |
| 六人 | Jev | — | 54.1% | 0.242 |
| 十人（有泄漏） | Gemini | 37.5% | 63.0% | 0.257 |
| 十人（有泄漏） | Qwen3-32B | 32.3% | 56.1% | 0.266 |
| 十人（有泄漏） | Jev | — | 56.1% | 0.241 |

**目前最有把握的观察是六人局的全桌判断随轮数改善。** 在同样 20 局上，Gemini 的具体身份准确率从第一轮 **17.5%** 升到第三轮 **40.0%**，配对变化 **+22.5 个百分点**，95% 区间 **[+9.2, +35.0]**。它同时获得更多对话、点车、票型及任务结果；当前实验不能把这段增益单独归功于语言理解。末轮基线的 60.8% 则回答“各局最后可见时能猜对多少”，与所有轮末等权后的 37.1% 口径不同。

**六人局的派西结果较弱。** Gemini 第一轮到第三轮从 52.5% 到 67.5%，变化 +15.0 个百分点，区间 **[−5.0, +32.5]**。从第二轮起，累计发言减仅本轮发言为 **−0.4** 个百分点，区间 **[−9.6, +9.8]**。因此尚无充分证据说旧发言本身稳定提高六人局的辨认率。总体二选一上，千问减 Gemini 为 −13.9 个百分点，区间 [−26.3, −1.4]；Jev 减 Gemini 为 −9.2，区间 [−27.5, +8.3]。

**十人局修复前只能报告输出特征。** 在同时有第一和第三轮的 14 局中，Gemini 全桌身份准确率从 29.3% 到 41.4%，派西从 57.1% 到 78.6%。第二轮起，累计发言比仅本轮高 15.5 个百分点，区间 [0.0, +32.6]。这些是受污染条件下的观测。即使修正名单顺序，两组仍同时改变了人数、语言、板子、线上打字／线下口语和剪辑方式，不能单独识别“人数”的因果效应。

## 7. 六人局个案：模型说某句话重要，删掉它会怎样？

我们事后挑选了 3 个变化明显的轮末。先让 Gemini 在看不到底牌的条件下，指出本轮可能影响预测的 1–3 条新记录；再分别用完整输入、删除所引记录、删除对照记录重跑。对照删除尽量匹配说话人和长度，每种条件独立抽样 3 次。部分个案还比较了某条发言或任务结果出现前后的截点。

| 对局与任务 | 结果 | 能支持的解读 |
|---|---|---|
| `9avmeG` 第三轮，全桌 | 模型引用一辆四人车及其任务成功作为依据。删除全部三条被引记录后，三次仍都猜对 6/6 个座位 | 摘出的这几条证据并非该预测的必要条件。坏人也能出成功牌 |
| `7ax9by` 第四轮，派西 | 归档预测给真梅林的概率从 28% 升到 99%。截至编号 96 的发言，三次复跑给 45%–70%；加入 97 号记录中另一名候选人自称忠臣的发言后，三次给 80%–85% | 这是值得继续验证的证据边界。删掉三条被引发言后，模型仍给真梅林 90%–95%，所以这次改判很可能还有其他依据 |
| `mep2bM` 第四轮，派西 | 归档预测给真梅林的概率从 95% 降到 38%。相同完整输入重跑三次，分别为 15%、80%、25% | 单次变化可以很大；把一次解释当作模型稳定的推理机制，证据不足 |

这组分析是事后选例，无法估计整套数据里有多少次改判来自类似原因。具体记录编号、模型解释、删句对照及每次输出都可复查。[个案证据与复跑汇总](../data/avalon-nlu/experiments/gemini-hydrogen-case-evidence-v1/summary.json)

在仓库根目录用 Node.js 运行下面的**离线反例**。预测函数只读实际发送的提示和候选座位，最后才读取真实底牌评分。预期输出为 22 局、104 个不同派西输入、104 次正确。字符串排序是复现泄漏的关键。

```js
const dir = './research/data/video-benchmark/experiments/ten-rounds-v1/';
const plan = require(dir + 'plan.json');
const scores = require(dir + 'scores.json');
const truth = new Map(scores.filter(r => r.task === 'roles').map(r => [r.game, r.actual]));
const jobs = plan.filter(j => j.task === 'percival' || j.task === 'recent');

function guessMerlin(messages) {
  const board = messages[0].content.match(/开局板子为([^。]+)/)[1];
  const candidates = messages[1].content.match(/候选座位：(\d+)、(\d+)/).slice(1);
  candidates.sort();
  return candidates[board.indexOf('梅林') < board.indexOf('莫甘娜') ? 0 : 1];
}
const hits = jobs.filter(j => truth.get(j.game)[guessMerlin(j.body.messages)] === 'merlin');
console.log(new Set(jobs.map(j => j.game)).size, jobs.length, hits.length);
```

## 9. 希望评审给出的意见

1. **泄漏的范围和修复验收。** 请独立运行反例，检查中文板子说明、角色映射、schema 枚举和 Jev 的 state。建议从与发牌无关的规则表生成固定顺序；做反事实测试：同一公开记录、同一板子、同一派西座位和候选集合，只交换梅林与莫甘娜底牌，实际请求应逐字节相同。还有哪些字段可能依赖评测标签？
2. **六人局结论能说多强？** 请分别判断“更多公开记录有助于猜全桌”“理解玩家话术”“记住旧发言有帮助”三句话受到多少支持。优先考虑只给公开行动、只给发言、打乱发言，以及互换候选顺序的对照，指出哪一项最能改变结论。
3. **统计与指标。** 42 局是两组独立对局，轮末和座位在局内相关。按局等权、同局配对和现有 bootstrap 是否足够？请评价单次抽样、录像缺轮、候选位置偏好，以及千问十人组角色张数违规对模型排名的影响。
