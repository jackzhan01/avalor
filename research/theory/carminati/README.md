# Hidden-Role Games：理论精读与实验桥接

2026-11-17 · 基线 `dev` / `463257d` · 只增加研究材料，未修改产品、历史实验或旧 proposal，未调用付费模型、提交或推送。

阅读版本为 Carminati、Zhang、Farina、Gatti、Sandholm 的 [arXiv:2308.16017v5](https://arxiv.org/abs/2308.16017v5)，**2026-03-02 修订，39 页**。已读正文与附录 A–E；引用使用从封面计数、与印刷页码相同的 PDF 页码。课程范围以本次最新任务为准，不承诺另建模型、提出新定理或解完整十人 Avalon。

**【论文已证明】核心模型与均衡。** 自然先分配 MAX／MIN 阵营，各人至少知道自己阵营，**每个坏人知道完整阵营分配**；好人可以有额外私有视野（Definition 3.1，p.10）。隐藏角色均衡 HRE 是通信扩展、人格拆分之后的 team max-min：好人先选整套局部策略与通信预算，再防知道该策略的坏人联合最佳回应。USplit 保留分散坏人的信息限制，CSplit 让一个敌方控制者汇总坏人观察。它不是普通 Nash，也没有免费授予好人共享秘密或全知视野（Definitions 3.3–3.6，p.12）。

**【论文已证明】正面结果有明确条件。** Theorems 4.1–4.3（pp.13–14）先用可信协调者的诚实上报／动作建议规范形归约到二人零和博弈，再用信息论安全 MPC 模拟协调者。需要私密且认证的信道、同步通信、坏人严格少数和协调敌方；价值可精确计算，有限协议给任意小误差实现。时间为 $|H|^{O(k)}$，固定坏人数才对显式历史树多项式；不是“十人牌型有限，所以完整游戏容易解”。

**【论文已证明／原文未解决】公开交流并非全未解。** Theorem 4.5 已在阵营公开的 2 对 1 游戏证明 NP-hard，4.6 对分散坏人给出公开交流的 $\Sigma_2^P$-hard；Proposition 5.1 还精确求解公开交流特例。§8（p.19）留下的是更一般的可计算性和类似 revelation principle 的通信结构刻画。固定有限预算，与对所有有限预算取 sup，是不同问题。论文五／六人 Avalon 的精确解依赖私下通信、角色互知和特定规则，不能当十人公开讨论基准。

**【仓库观察】本次最重要的适用性发现。** 十人牌型含奥伯伦，已不满足“坏人都知道完整阵营”。`evil-coordination.ts` 又读取真实发牌并向互认坏人提供具体角色，agent 层还拒绝未指定者的坏票。本轮纯函数交换检查确认：标准视野相同，协调输出却不同。这是额外信息授权和策略限制，不能仅称标准规则内的预先约定。

**【解释／假设】实验路线。** 优先做三件事：同局同截止点的发言消融；协调信息与执行约束的离线审计；固定其他九座策略的单席证据处理对照。按完整局划分、配对与报告不确定性；分别量身份概率、任务、刺杀和最终阵营收益。历史第三局 m3 的 A/B 均为 60% 阵营准确率，本轮已核对输入哈希并重算评分，但一次采样不能裁决语言价值。

**核读保留。** v5 Theorem 6.3 显示式与定义／证明的倒数方向不一致；正文 4.3 的 polylog 通信界与附录 B.3 的电路规模依赖也未充分衔接。笔记明确标注原文与保守读法，不静默修订。没有重证底层 MPC 文献、复现论文求解器或调查全部后续研究。
