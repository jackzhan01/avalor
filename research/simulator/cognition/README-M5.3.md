## 一、这个里程碑为什么存在

M5.2 那一局打完之后，我写的报告里有一句话是**错的**：

> 「最尖锐的一点：它全都做对了，然后输了。」

真派西维尔（8号）在公开 sequence 45 和 58 说了同一句话：

> **「7、9一梅林一莫甘娜」**

那就是规则私下给它的候选对，**一个字不差**。而 7号 正是抢跳的莫甘娜。
这一句话把梅林从六个好人缩到两个人，其中一个还是坏人 —— 等于直接告诉刺客梅林是 9号。

**动作选对了，信息泄光了。** 这两件事必须分开评价，而我上一份报告把它们合成了一个「做对了」。

### 它不是一次偶然

用 [`scripts/render-turn-prompt.ts`](../scripts/render-turn-prompt.ts) 把那两次决策的**真实历史提示**
逐位重建出来（`promptKey` 校验通过，十项元数据全对），提示里同时命中了**九条**措辞：

- **四条在推它说** —— 其中 `ecc.percival-claim-tradeoff` 直接写着
  「换到的：**把候选对变成公开的组织依据**」，而且带 `obligation: true`（必须看到）。
- **五条本该拦住而拦不住** —— 包括 `ec.percival-do-not-rank-the-pair-publicly`，
  **唯一一条保护性条目，就在同一份提示里**，模型读了，照样说了。

而且 M5.2 的 schema 里有一个 `informationToConceal` 字段，让模型自己声明「这一步绝对不能漏出去的东西」。
8号 **每一步都填对了**：「不能泄露我认识 2、3 号，也不能表现出对真正梅林位置有确定判断」。
然后它把候选对说了出去。

**一个由说话者自己定义的秘密，不是秘密，是一条笔记。**

所以 M5.3 的前提是：**再加一条「不要说」不会有用，M5.2 已经加过了。**

## 二、机制：发言的那一段拿不到那个值

```
prompt-0.4.0（融合）                       prompt-0.5.0（分离）

┌──────────────────────────┐             ┌──────────────────────────┐
│ 一次请求                 │             │ ① 私有规划者             │
│  身份层（真实身份）      │             │   身份层（真实身份）     │
│  私有信息层（候选对）    │             │   私有信息层（候选对）   │
│  推理记录（完整账本）    │   ──▶       │   推理记录（完整账本）   │
│  公开记录 + 派权表       │             │   公开记录 + 派权表      │
│  ↓                       │             │   ↓ 动作 + CommunicationIntent
│  动作 **和** 公开发言    │             └───────────┬──────────────┘
│  在同一次生成里产出      │                         │ 防泄露闸
└──────────────────────────┘                         ▼
                                         ┌──────────────────────────┐
                                         │ ② 公开发言者             │
         同一段文本                       │   **没有**身份           │
         既看得到候选对                   │   **没有**候选对         │
         又要写给牌桌听                   │   **没有**账本           │
                                         │   只有公开记录 + 信封    │
                                         │   ↓ 一句话               │
                                         └───────────┬──────────────┘
                                                     ▼ 成句后再查一次
```

**关键不是多了一道检查，是发言者手上根本没有那个值。**
一个没拿到候选对的模型，不会因为被说服、被绕过、或者自己想帮忙就把它说出来 —— 它没有可说的。

### 这是一个类型上的保证，不是一条纪律

[`spokesperson.ts`](./spokesperson.ts) 里的 `PublicTableView` 只有三个字段：

```ts
export interface PublicTableView {
  readonly seat: Seat;
  readonly position: PositionView;
  readonly publicLog: readonly PublicEvent[];
}
```

没有 `role`、没有 `side`、没有 `knowledge`、没有 `ladyResults`、没有 `evilRoster`、
没有 `evilDiscussion`、没有 `memory`、没有 `request`。**加任何一个都是有人要专门去改的编译期改动**，
而那个文件的头部写了为什么不要改。

`Observation` 在结构上是 `PublicTableView` 的超集，所以一个 `as` 就能骗过编译器 ——
`assertPublicOnly` 在运行时再拒一次。这和 `buildPlayerPrompt` 里那道 `assertNoRefereeState` 是同一种锁。

### 证明的方式是逐字节比较

造两局**只在隐藏信息上不同**的对局，固定公开状态和已选动作，要求发言者的两条消息完全一样：

| 换掉的东西 | 断言 |
|---|---|
| 派西维尔候选对 | system 与 user 逐字节相同 |
| 座位的真实身份 | 同上 |
| 坏人名单 | 同上 |
| 女神真实结果（宣布值不变） | 同上 |

见 [`noninterference.test.ts`](./noninterference.test.ts)。
**「有没有提到那一对」测的是检测器；「字节是不是一样」测的是那个值根本没进来过。**

配对断言同样在那里：规划者的提示**确实会变**。否则 M5.3 就不是把信息关住，而是把信息删掉了。

## 三、开发过程中这组测试抓到的两个真实缺陷

写下来，因为它们说明为什么这些测试值得。

**1. 秘密类别清单本身就是身份信号。**
第一版把「这个座位持有哪几类秘密」渲染进了发言者提示 —— 想法是「说类别比说值安全」。
不够安全：「你持有梅林视野」等于报出身份，「你持有派西维尔候选对」把范围缩到一个人。
**身份替换那条测试当场红了。** 现在发言者拿到的是 `ALL_SECRET_CLASSES` ——
**恒定的七类清单，每一局每一个座位都一样**，既是字节不变的，也是真的（这七类谁都不许说）。
座位实际持有什么只进私有审计。

**2. 信封的填写说明根本没接进提示。**
一次静默失败的字符串替换，让 `INTENT_INSTRUCTION` 从来没有进过规划者的 user 消息。
脚本化的双面客户端不读说明，所以端到端测试全绿；**只有那条专门断言提示内容的测试发现了它**。
真跑起来的话，模型会拿到一个 `communicationIntent` 的 JSON schema，却没有任何关于怎么填的中文说明。

## 四、信息分级（[`classification.ts`](./classification.ts)）

**系统所有。** 每一个标签都从裁判自己的数据算出来：id 的形状、注册表条目、座位的观测。
**这个文件里没有任何一行读模型写的字段，也不能有。**

| 秘密类别 | 频道 | 能否解密 | 通过什么 | 公开出去的是什么 |
|---|---|---|---|---|
| 自己的身份 `p.self` | 座位私有 | **可以** | `speech.claim` | 一个**声称** —— 「他这么说」，不是任何私有信息的内容 |
| **派西维尔候选对 `p.pair`** | 座位私有 | **永远不行** | — | — |
| 梅林视野 `p.sees` | 座位私有 | **永远不行** | — | — |
| 坏人名单 `p.team` / `p.roster` | 坏人密谈 | 永远不行 | — | — |
| 女神真实结果 `p.lady…` | 需合法动作解密 | **可以** | `lady_announce` | **宣布的那个值，而且它可以是假的** |

公开事实 `f…`、推导事实 `f.now`/`f.fail…`、说法 `c…`、派权事件 `k…` 全部是牌桌公开。

**两条值得单独说的：**

- **跳派西维尔不解密候选对。** 声称公开的是「他这么说」。这一条是整个里程碑的支点：
  它让「跳」这个动作完整保留，同时让那一对留在原地。
- **女神：真实结果和宣布的值是两件事。** 宣布这个动作解密的是**宣布本身**，
  而且宣布的可以是谎。裁判给的答案永远不会因为任何发言变成公开的。

**推导结论继承前提里最强的那一条隐私。**
一条建立在 `f12` 和 `p.pair` 上的约束是 `p.pair` 级的。
这是账本里「结论最多和最弱的前提一样硬」的镜像 —— 硬度和隐私沿着同一条边往相反方向走。

## 五、信封（[`intent.ts`](./intent.ts)）

跨过闸的**唯一**一样东西。别的全部停在这里，因为它们不在这个类型里。

```
channel                     频道，由任务决定，规划者说了不算
publicGoal                  这一步想达成什么
targetSeats                 针对谁
selectedClaimAction         已经选好的公开身份动作（九个之一）
requestedTeam               要求的车
requestedVote               要求的票
publicBasisIds              只解析公开 id
publicProposition           一句可以被同意或拒绝、而且别人能自己核对的话
desiredTableEffect          希望牌桌接下来做什么
─────────────────────────────────────────────────────────
factsThatMustRemainPrivate  **系统算的**，不是模型填的
```

最后那一条是对 M5.2 的直接回应。`informationToConceal` 是模型写的，
它写得完全正确，然后照样泄露了。**信封里这一项由系统给，而且给的是恒定的七类清单**（见第三节）。

规划者的 schema 里**没有** `publicMessage` —— 它被删掉了，换成信封。
所以「规划者不写措辞」不是一条它可能漂移的指令，**它根本没有那个字段可以漂移进去**。

## 六、防泄露闸（[`firewall.ts`](./firewall.ts)）

两个岗位，失败方式故意不同：

### 过闸之前：清洗信封

- **公开依据 id**：拿一个 `publicOnly(registry)` 去解析。私有的、编造的、过时的，一个都不放行，
  而且**每一个都被记下来**（是私有还是查不到，理由分开写）。
  这是一个**独立的对象**，不是查表时加个过滤 —— 过滤是一条会被忘记的规则，
  一个从来没装过私有条目的对象，怎么用都漏不出来。
- **文本字段**：带秘密的字段**整段替换**成一句固定的标记。
  不是抠掉一部分 —— 把一句话里的候选对抠掉，剩下的还是那个意思。
- **频道**：由任务决定。规划者写 `evil-council` 也不会拿到密谈频道的发言者。

### 成句之后：最后一道闸

- 不进公开日志、不给任何别的智能体看；
- **不把被拦下的句子回喂给发言者当修复提示** —— 回喂等于把它刚要泄露的东西再递一次；
- 用**一模一样**的提示重发（和输出容量重试同一个道理：请求本身没有错）；
- 超过 `stages.maxPublicMessageRepairs` 就以 `disclosure_invalid` 停下，**不放行、不改写**。

### 检测器的边界，说清楚

[`secrets.ts`](./secrets.ts) 的 `findDisclosures` 是一个**中文文本匹配器**，两层规则：

- **A 层 · 分句精确**：某个分句正好只点了那一对，并且提到梅林／莫甘娜／候选 → 拦下。
- **B 层 · 短语绝对**：`一梅林一莫甘娜`、`我的候选对` 这类**没有无辜读法**的短语，
  只要那一对两个座位都出现在句子里 → 拦下。

**A 层为什么要求「正好」：** 不加这个条件，
「6、7、9 里可能有莫甘娜」也会被拦 —— 那是一条从挂掉的车推出来的普通公开推理，
删掉它就是在删这个模拟器要研究的东西，而且是无声地删。
`firewall.test.ts` 里专门有一条断言要求它**必须放行**。

**这道闸是纵深防御，不是主要机制。** 一个中文文本检测器不可能完备。
主要机制是第二节那件事：发言者手上没有那个值。
**这份文档不打算把检测器说得比它实际更强 —— 说过头，下一个人就会依赖它。**

## 七、策略档：`expert-disclosure-safe`

`expert-claim-contest` 的全部内容，**减去七条**会把候选对推向公开的条目，换成对应的安全版本。

| 被替换的 | 问题在哪 |
|---|---|
| `ecc.percival-claim-tradeoff` | 「把候选对变成公开的组织依据」 |
| `ecc.percival-claim-must-be-actionable` | 「带上可执行的东西：候选对怎么处理」 |
| `ecc.percival-fight-the-rival` | 「打他的候选对故事」 |
| `es.percival-pair-same-team-crosses-a-line` | 「沉默地投反对既救不了这一轮」 |
| `ec.percival-pair-same-team` | 「越等于自报身份并点出候选对」 |
| `ec.percival-early-claim-default` | 说跳派的代价是缩小梅林范围 —— 0.5.0 之后这句不再成立 |
| `ec.percival-do-not-rank-the-pair-publicly` | 条件性的（「没有明确回报」），而且只管排序不管报出 |

**是替换，不是删除。** 每一条都有对应的 `eds.*`，同一个决策还在，
换的只是**公开理由从哪里来**。跳、对跳、拖、打竞争者、否车、设检验 —— 一个动作都没少。

多出来的两条给桌面这一侧：

- `eds.do-not-ask-for-the-pair` —— **追问「你的两个候选是谁」等于替刺客提问。**
- `eds.pair-story-is-not-evidence` —— 「他给了一对」不是核实。见第九节。

**这份策略档不是机制。** M5.2 的提示里就有一条保护性条目，模型读了，照样说了。
这些条目存在，是为了在不安全的那条路被拿掉之后，**规划者还有地方可去**。

## 八、体量、调用与成本（在 M5.2 的真实位置上实测）

不是估的：[`scripts/m5-3-review.ts`](../scripts/m5-3-review.ts) 重放那一局，
在**每一个决策点上真的把 0.5.0 的两段提示建出来**再量。

| 单次请求输入（字符） | 0.4.0 实测 | 0.5.0 规划者 | 0.5.0 发言者 |
|---|---|---|---|
| 中位 | 18,385 | 20,401 | 3,868 |
| p90 | 21,319 | 23,209 | 5,575 |
| 最大 | 23,417 | 25,932 | 6,989 |

- **输入 token 约 1.16×**（已乘 M5.2 实测的估算器偏差系数 0.4827）。

**成本**（2026-08-27 更新，Luna 官方价目已配置）：

| 配置 | 可能 | 最坏（发言者撞满 3,000 且用满重发额度）|
|---|---|---|
| ① Terra + Terra | $8.57 | **$11.77** |
| ② Terra + Luna（仅参考）| $7.98 | $8.30 |
| ③ Luna + Luna | $0.86 | **$1.18** |

三种配置都不触发 $12 提醒线、不撞 $25 单局硬闸；①③ 各跑一局最坏合计 $12.95，
从 $30.5825 累计到 $43.53，$100 批量余额 $56.47。

**一个仍然测不出来的量**：发言者的 reasoning token。这一段一次都没跑过。
`medium` / `3,000`（人于 2026-08-27 定）仍是**推的，不是测的** ——
但给上限不花钱，只有真用掉的 token 才计费，而上限给小了会在第一局撞成硬失败。

## 九、一个设计带来的新不对称（**需要人来定，我没有替它决定**）

闸拦的是**真实**候选对。所以：

- **真派西维尔**不能公开讲那一对；
- **莫甘娜**（手上没有真候选对，她不知道谁是梅林）可以随便编一个公开讲，检测器不会响。

于是「敢报一对」会慢慢变成「不是真派」的软线索 —— 这**加重**了真派西维尔的处境，
而这个里程碑本来是为了保护它。

**2026-08-27，人做了决定：保持现状。** 假声称者可以编一个候选对故事并公开讲；
这样的故事永远只是一个公开说法，不是身份的证据；巧合猜中真实那一对**不算泄露**；
**不做全局禁止**；`eds.pair-story-is-not-evidence` 和「追问候选对等于替刺客提问」两条都保留。

[`false-claims.test.ts`](./false-claims.test.ts) 把这个决定写成了断言：
同一句 「7、9一梅林一莫甘娜」，真派西维尔说 → 拦下，莫甘娜说 → 放行。
**闸只认说话人自己的秘密。**
